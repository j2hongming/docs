    L3

    • SVI(Swtich VLAN Interface)
      • 某個 VLAN 在交換器上的虛擬閘道介面；主機把預設閘道指到它，才能離開自己的 VLAN
      • 管「這個 VLAN 的 IP 介面」，負責跨 VLAN
      • 一個 VLAN 對一個 SVI（例如 VLAN 100 → vlan100）
      • 同 VLAN 主機設這個 IP 為預設閘道，才能跨 VLAN
    nv set interface vlan10 ip address 10.0.10.2/24
nv set interface vlan10 ip address 2001:db8::1/40

    VRR(Virtual Router Reduandancy)

    active-active traffic

    VRR 把「預設閘道」做成兩台 leaf 共用的虛擬路由器，主機只設一個 IP，交換器側可備援且可兩邊同時轉發。對閘道 10.1.10.1 來說： - 主機／VM 問「誰是 10.1.10.1？」 - leaf01 與 leaf02 都可以回，且回的 MAC 相同 - 因此任一路徑（eth1→leaf01 或 eth2→leaf02）都能當有效閘道 → active/active - 主機 ARP 表裡閘道只會是一個 IP + 一個虛擬 MAC；背後兩台交換器都能處理打到這個 MAC 的流量。

    nv set interface vlan10 ip vrr address 10.1.10.1/24
nv set interface vlan10 ip vrr mac-address 00:00:5E:00:01:10
nv set interface vlan10 ip vrr state up
nv config apply
    • 兩台 leaf 都要設 相同的 VRR IP 與相同的虛擬 MAC，才會變成同一個虛擬閘道（active/active）
    • Best practice
      • 建議虛擬 MAC 落在 VRRP 保留範圍：
        • 00:00:5E:00:01:00～00:00:5E:00:01:ff
      • IETF 為 VRRP 保留的 OUI／位址區間（標準虛擬路由器 MAC 型式大致是 00-00-5E-00-01-{VRID}）
    VLAN 10 的主機
    │
    │  預設閘道 = 10.1.10.1   ←── 主機只認這個（VRR 虛擬 IP）
    ▼
┌─────────────────────────────────────┐
│  leaf01 / leaf02  的  SVI vlan10     │  ←── 真正的 L3 介面（連 bridge、有路由能力）
│    ├─ 本機 IP（可選，各葉自己的）      │
│    └─ VRR: 10.1.10.1 + 虛擬 MAC      │  ←── 對外「共用閘道」身份

    實務上常見組合：每台 leaf 的 vlan10 有自己的 SVI IP（管理／路由用），再加一組 VRR 給主機當預設閘道。

    server01上ping 10.0.20.102，實際上流量如何傳遞

    去程（ICMP Echo Request） 

    [1] server01
    目的 IP 10.0.20.102 不在 10.0.10.0/24
    → 查路由：丟給 GW 10.0.10.1
    → ARP：10.0.10.1 → 虛擬 MAC 00:00:00:00:1a:10
    → 送出 untagged Ethernet（目標 MAC = VRR MAC）
[2] leaf01  swp1 (access 10)
    收到 untagged → 歸入 VLAN 10
    目標 MAC 是本機 VRR → 交給 L3（SVI vlan10）
[3] leaf01  路由
    來源介面：vlan10 (10.0.10.0/24)
    目的：10.0.20.102 → 連接到 vlan20
    TTL-1，改寫 L2：
      src MAC = leaf 在 VLAN20 的 MAC（或 VRR 相關轉發行為）
      dst MAC = server02 的 MAC（VLAN20 上 ARP／MAC 表）
[4] leaf01 → leaf02（若 server02 MAC 是從 peerlink 學到）
    從 bond0 送出，802.1Q tagged VLAN 20
    leaf01:swp49/50 ──► leaf02:swp49/50
[5] leaf02
    bond0 收到 tagged VLAN 20
    MAC 表：server02 在 swp2
    → 從 swp2 送出 untagged（access 20）
[6] server02
    收到 ICMP request（目的 IP 是自己）

    回程（ICMP Echo Reply） 

    server02 → GW 10.0.20.1 (VRR) → 多半進 leaf02 做 vlan20→vlan10 路由
         → 若目的 10.0.10.101 的 MAC 在 peerlink 對岸
         → bond0 tagged VLAN10 → leaf01 → swp1 untagged → server01

    沒有 VRR／SVI：同 VLAN 才通，跨網段 ping 不通。 沒有 bond0 trunk：leaf01 路由進 VLAN 20 後，到不了只接在 leaf02 上的 server02。

    BGP Unnumbered

    用 IPv6 link-local 建 eBGP，靠 RFC 5549 帶 IPv4 路由，介面不必再配一堆點對點 IPv4。

    VRF(Virtual routing and forwarding)

    enables you to use multiple independent routing tables that work simultaneously on the same switch.

    Other implementations call this feature VRF-Lite (local).
